<h1 align="center">Starbucks ☕️💚</h1>

**Starbucks Clone** é uma recriação moderna da interface do usuário da Starbucks. Este projeto foi desenvolvido para aprimorar habilidades em **React**, **Vite** e **Tailwind CSS**, focando na componentização, performance e em um design responsivo e fiel à marca.

**[Ver Projeto Online]( http://localhost:5173/)**

---

## ✨ Funcionalidades Principais

* **🎨 Design Fiel e Responsivo:** Uma interface que se adapta perfeitamente a dispositivos móveis, tablets e desktops, mantendo a identidade visual da Starbucks.

* **🧩 Arquitetura de Componentes:** A interface foi dividida em pequenos blocos reutilizáveis (Header, Hero, Cards, Footer) para facilitar a manutenção e escalabilidade.

* **⚡ Estilização Ágil com Tailwind:** Uso de classes utilitárias para construir layouts complexos rapidamente, sem sair do HTML/JSX.

* **🖼️ Troca Dinâmica de Imagens:** (Se aplicável ao seu projeto) Funcionalidade que altera o copo em destaque e a cor de fundo conforme a interação do usuário.

* **🚀 Performance Otimizada:** Carregamento ultra-rápido graças ao bundle gerado pelo **Vite**.

---

## 🛠️ Tecnologias e Ferramentas

* **React:** Biblioteca JavaScript para construção de interfaces interativas baseadas em estados.

* **Vite:** Ferramenta de build de próxima geração que proporciona um servidor de desenvolvimento extremamente rápido (HMR).

* **Tailwind CSS:** Framework de CSS "utility-first" para estilização direta e consistente.

* **JavaScript (ES6+):** Lógica moderna para manipulação de eventos e dados.

* **ESLint:** Ferramenta de linting para garantir a qualidade, padronização e limpeza do código.

---

O projeto segue uma estrutura organizada padrão do Vite + React, facilitando a localização dos componentes.

## 🚀 Como Executar

Siga as instruções abaixo para configurar e executar o projeto em seu ambiente local.

### Pré-requisitos

* [Node.js](https://nodejs.org/en/) (versão 18.x ou superior)
* [npm](https://www.npmjs.com/) ou [Yarn](https://yarnpkg.com/)

### Instalação

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/starbucks.git
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd starbucks
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```

### Executando o Projeto

Para iniciar o servidor de desenvolvimento com **Hot Module Replacement (HMR)**:

```bash
npm run dev
```
