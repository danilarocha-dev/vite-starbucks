# Starbucks ☕️

Este é um projeto de recriação da interface do usuário do site da Starbucks, desenvolvido com o objetivo de aprimorar as habilidades em desenvolvimento front-end moderno, com foco em design responsivo e interativo.

## ✨ Visão Geral

O projeto consiste em uma landing page que apresenta os produtos e a marca Starbucks, utilizando uma abordagem de componentes reutilizáveis e estilização moderna para criar uma experiência de usuário agradável e fluida.

## 🚀 Tecnologias Utilizadas

- **React + Vite:** Para uma base de desenvolvimento rápida e moderna.
- **Tailwind CSS:** Para estilização utilitária e eficiente.
- **JavaScript (ES6+):** Para a lógica e interatividade dos componentes.
- **ESLint:** Para garantir a qualidade e a consistência do código.

## 🏁 Começando

Siga as instruções abaixo para configurar e executar o projeto em seu ambiente local.

### Pré-requisitos

- [Node.js](httpss://nodejs.org/en/) (versão 18.x ou superior)
- [npm](httpss://www.npmjs.com/) ou [Yarn](httpss://yarnpkg.com/)

### Instalação

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/starbucks.git
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd starbucks
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```

### Executando o Projeto

Para iniciar o servidor de desenvolvimento, execute o seguinte comando:

```bash
npm run dev
```

Abra [http://localhost:5173](http://localhost:5173/) em seu navegador para ver a aplicação.

## 📜 Scripts Disponíveis

- `npm run dev`: Inicia o servidor de desenvolvimento.
- `npm run build`: Gera a versão de produção do projeto.
- `npm run lint`: Executa o linter para verificar o código.
- `npm run preview`: Inicia um servidor local para visualizar a versão de produção.
